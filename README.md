### 📦 Inventory Management Ecosystem

Building an inventory-management system designed around actual business workflows rather than a demo dataset.

```text
React Native
     │
     ▼
 MVVM Architecture
     │
     ├── ViewModels
     ├── Repositories
     └── Dependency Injection
     │
     ▼
   Supabase
     │
     ├── Authentication
     ├── Profiles
     ├── Inventory
     └── Role-Based Access
```

Features include:

* Inventory tracking
* Admin / Moderator / Viewer roles
* Role-based editing permissions
* Product/category management
* Stock-level monitoring
* Authentication architecture
* Future low-stock notifications
