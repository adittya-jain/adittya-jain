### 📦 Inventory Management Ecosystem

A React Native inventory system designed around **actual business workflows**, rather than a demo CRUD application.

```text
React Native
     │
     ▼
    MVVM
     │
     ├── ViewModels
     ├── Repositories
     └── Dependency Injection
     │
     ▼
  Supabase
     │
     ├── Authentication
     ├── Profiles
     ├── Inventory
     └── Role-Based Access
```

Built around:

- Inventory & stock tracking
- Admin / Moderator / Viewer roles
- Role-based permissions
- Product & category management
- Authentication architecture
- Low-stock monitoring
